怎么拿到 API 密钥（三分钟）

1. 打开 console.cloud.google.com，登录谷歌账号。

2. 顶部新建项目（名字随便），进入后点左侧「API 和服务」→「库」，搜索 YouTube Data API v3，启用。

3. 左侧「凭据」→「创建凭据」→「API 密钥」，复制那串以 AIza 开头的字符串，粘回本页。

如果在第 3 步给密钥加了「网站限制」，要把本页域名加进白名单，否则网页里调用会被拒。 刚开始用可以先选「无限制」，跑通了再加限制。

这个工具在算什么

游戏线：转化分 = 生存建造占比 45 + 攻略/百科占比 20 + 沙漠废土占比 15 + PC/主机占比 20；手游占比超过 25% 直接扣 25 分。

影视线：转化分 = 决策向 35 + 榜单向 25 + 科幻史诗 30 + 电影纯度 10；不是真电影号（影视词少于 25% 或韩剧综艺噪音超过 40%）扣 30 分。

硬标准：订阅 1000～50000、地区 KR、内容相关、播放量真实。上限 5 万是铁律，超了是 KOL 不是 KOC。

几个已经踩过的坑

· 韩国频道标题常常不写游戏名，占比会失真，看到「未识别」比例高就人工核一下标题原文。

· 播放量高不等于能转化。低龄向沙盒号均播可以很高，但转化不到买断制成人向游戏。

· 出表前一定看活跃度，只看内容分会混进停更一两年的号。

· 联系方式按三个来源查：频道简介 → 全部视频简介 → Telegram / 开放聊天室。只查频道简介会漏掉约三分之一。
