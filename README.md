用 YouTube Data API v3 在浏览器里直接筛选韩国小体量创作者，自动打分、排查目标 IP 接触史、整理成表。整个站点是纯静态网页，没有后端，也不需要安装任何东西。

## 在线使用

仓库开启 GitHub Pages 之后会生成一个公开链接，打开就是工具本身。填自己的 YouTube Data API v3 密钥，选一条线，点开始挖掘即可。密钥只存在本人浏览器的 localStorage 里，页面不会把它发到任何服务器。

## 页面上的三个页签

批量挖掘可以填密钥、选游戏线或影视线、设最多深挖几个频道，跑完直接在页面上出一张 11 列的表。推荐理由和备注两列可以直接点进去编辑，改完导出 CSV 或 HTML。没有密钥也能点「看演示数据」，先看清楚表格长什么样。

单频道体检适合先验证口径。贴一个频道链接或 @handle，会拉最近 200 条视频，算出订阅数、地区、均播、中位播放、平台占比、转化分、目标 IP 接触史、联系方式和最近更新时间，下面还列最近 15 条标题供人工核对。这条路径最省配额。

第三个页签写了去 Google Cloud Console 申请密钥的三步流程。

## 密钥的网站限制

如果给密钥加了 HTTP 来源限制，需要把 Pages 域名加进白名单，否则浏览器里调用会被拒绝。页面内也提示了这一点。

## 离线 Python 工具包

`downloads/koc-toolkit.zip` 是同一套逻辑的本地脚本版，适合想改词表或者批量跑的人。解压后先看 START_HERE.html。脚本从根目录的 api_key.txt 读取密钥，也支持环境变量 YOUTUBE_API_KEY，校验不通过会直接退出。

## 关于数据

仓库里不含任何真实 API 密钥、已审频道池或创作者联系方式。离线包里的排除池是空的，从零开始挖，不会撞到任何历史名单。

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000 即可。直接双击 index.html 也能用，浏览器允许跨域调用 Google API。
