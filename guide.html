KOC API 挖掘工具包

用 YouTube Data API v3 批量挖韩国 KOC（小体量创作者）并自动打分、排查、出表的 Python 工具集。 零依赖，只需 Python 3.7+，不用 pip 装任何东西。

下载工具包
koc-toolkit.zip（51 KB）
解压后双击 START_HERE.html 就是本页的本地版；这一份是干净版， 只含脚本和说明，不含任何历史频道数据。
这个包解决什么问题：找一个「没做过某 IP 相关内容、但观众能转化成目标受众」的韩国 KOC。 工具会自己做四件事——按真人搜索词批量召回 → 用平台/玩法/形态占比算转化分 → 逐频道排查目标 IP 历史内容 → 抓联系方式并出 HTML 表。

一、三分钟开始

第 1 步：装 Python（Mac 基本自带）

打开「终端」，输入 python3 --version。能看到 Python 3.x.x 就行。Mac 如果没有，去 python.org 装一个。

第 2 步：填你自己的 API 密钥

双击 setup_api_key.command，按提示粘贴密钥。没有密钥？三步拿到：

  1. 打开 https://console.cloud.google.com/，登录谷歌账号；
  2. 新建项目 → 左侧「API 和服务」→「库」→ 搜 YouTube Data API v3 → 启用；
  3. 「凭据」→「创建凭据」→「API 密钥」→ 复制那串以 AIza 开头的字符串。

密钥会写进本目录的 api_key.txt。这个文件只留在你本地，别跟着包一起转发给别人。也可以不建文件，直接设环境变量 export YOUTUBE_API_KEY=你的密钥。

第 3 步：选一条线跑

双击 run_game_line.command（游戏类）或 run_film_line.command（影视类），全程自动跑完，最后在 scripts/ 目录里得到 HTML 表和 CSV。

Mac 双击打不开？因为文件是从网上收下来的，系统会拦一道。 解决办法：在文件上点右键 → 打开 → 再点一次「打开」。只需要这样弄一次，以后双击就能直接跑。 不想双击也可以在终端里跑：cd 到本目录，输入 ./run_game_line.command。

二、两条线分别是什么

线目标判据
游戏类 把观众转化成「某款游戏」的玩家 看平台对不对（PC/主机 vs 手游）、玩法对不对（生存建造/开放世界/沙漠废土）、是不是攻略型内容
影视类 把观众转化成「某部电影」的购票观众 看是不是真电影号、有没有决策影响力（推荐/解说/榜单）、是不是科幻史诗调性、形态偏剧透解说还是前瞻分析

两条线各算各的、互不折算——游戏号的终点是玩家，影评号的终点是电影观众，混在一起算会两边都失真。

四、游戏线流程（六步）

cd scripts
python3 find_dune_game_koc2.py                          # ① 召回：按游戏名+意图词搜，排除历史频道
python3 dg2_s3_score.py                                 # ② 打分：转化分 + 硬门槛 gate
python3 pick_top.py dg2_s3_scored.json dg2_picks.json 40 30   # ③ 挑前 40 名（分数≥30）
python3 dg2_s4_contacts.py dg2_picks.json dg2_s4.json   # ④ 排查目标 IP + 抓联系方式 + 均播活跃度
python3 check_vertical.py                               # ⑤ 单游戏垂直度：观众跟游戏走还是跟人走
python3 make_table_auto.py dg2_s4.json 游戏类 我的游戏线KOC  # ⑥ 出 HTML + CSV

转化分怎么算

生存建造占比 45 + 攻略/百科占比 20 + 沙漠废土占比 15 + PC/主机占比 20，手游占比超过 25% 直接扣 25 分。 排序逻辑是攻略型优先于纯实况型——愿意做攻略，说明观众已经在玩，不是来看热闹的。

六、硬标准与已知坑

KOC 硬标准：订阅 1000～50000，韩国（country == KR），内容相关，播放量真实。 上限 5 万是铁律，超了是 KOL 不是 KOC；下限 1000 是为了排除没有有效受众的号。
几个已经踩过的坑，别再踩：
  • 标题里不写游戏名在韩国很常见，占比类指标会失真，一定要把「未识别」的标题原文拉出来人工核一遍。
  • 播放量高不等于能转化。低龄向沙盒号（Minecraft 系）均播可以很高，但转化不到买断制成人向游戏；影视线同理，童话寓言解说号、网飞剧集号均播很高但完全不对口。
  • 出表前必须核活跃度，只看内容分会混进停更一两年没人管的号。
  • 联系方式三个来源要按序查：频道简介 → 全量视频简介 → 非邮箱渠道（Telegram / 开放聊天室）。只查频道简介会漏掉约三分之一。
  • YouTube 官方的「含付费推广」徽章抓不到，别往这个方向试。判断是否接过商单，改看创作者自披露的 광고/협찬/PPL/제휴 等字样。

七、配额与耗时

免费额度是每天 10000 单位，一次搜索 100 单位。全流程建议控制在每天 150～250 个候选以内，跑不完第二天接着跑。 第 ④ 步最费配额，每个频道要 1 次搜索 + 1 次频道查询 + 若干次列表拉取，这也是为什么要先用 pick_top.py 砍一刀。

八、两个旧脚本说明

dg2_make_table.py 和 df_make_table.py 是 2026-10 那一批成果的出表脚本， 里面硬编码了当时的人工判断（视频内容类型、推荐理由、备注），只能用来复现那两张旧表。 跑自己的新数据请用 make_table_auto.py，它会按同样的 11 列格式自动生成，推荐理由和备注留空待你人工补。

九、输出的表格长什么样

固定 11 列：分类 / 用户名 / 平台 / 平台链接 / 粉丝量 / 视频内容类型 / 均播 / 活跃度 / 邮箱 / 推荐理由 / 备注。 视频内容类型按四个维度写：类型、平台占比（游戏线）或形态占比（影视线）、受众、视频风格。 想看成表的实际格式，可以直接在网页应用里点「看演示数据」。
